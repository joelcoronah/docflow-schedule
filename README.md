# DocFlow Frontend

React + Vite frontend for DocFlow dental practice management system.

## Quick Start

```bash
# Install dependencies
npm install

# Setup environment
echo "VITE_API_URL=http://localhost:3000/api" > .env

# Start development server
npm run dev
```
